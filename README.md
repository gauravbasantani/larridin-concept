# Larridin concept

An unofficial design concept by Gaurav Basantani ([gauravbasantani.com](https://gauravbasantani.com)): a finance view that shows how sure an AI return number is, where it comes from, and the renewal call it supports. It is not affiliated with or endorsed by Larridin, and the company, team and numbers in it are made up. Live page: https://gauravbasantani.github.io/larridin-concept/
